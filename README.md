# Smart Renewable Energy Management System

## Overview
A MATLAB/Simulink-based Smart Renewable Energy Management System with Adaptive Load Shedding for a residential PV microgrid using a Hybrid Energy Storage System (Battery + Supercapacitor).

## Features
- Hybrid Energy Storage System (Battery + Supercapacitor)
- Adaptive Load Shedding using Stateflow
- NASA POWER weather data
- PV generation and MPPT
- Five-level Cascaded H-Bridge Inverter
- 24-hour residential microgrid simulation

## Software
- MATLAB R2025a
- Simulink
- Stateflow

## Project Structure
- MATLAB_Simulation/
- Weather_Data/
- Images/
- Results/
- Documentation/

## How to Run
1. Open MATLAB R2025a.
2. Run `RUN_ALL.m`.
3. Open `microgrid_top_fixed_final.slx`.
4. Start the simulation.
